# DopMi landing mockup

Prototipo visual de la landing de DopMi, restaurado desde el proyecto fuente proporcionado por el equipo. Las tarjetas de casos y los flujos de donación que aparecen en esta página son demostrativos; esta versión todavía no está preparada para anunciar pagos reales ni publicar información legal definitiva.

## Desarrollo

```sh
npm ci
npm run dev
```

## Build estático

```sh
npm run lint
npm run build
```

En Vercel, importa este repositorio como proyecto Vite. Usa `npm run build` como Build Command y `dist` como Output Directory. No se necesitan variables de entorno para esta versión.

Antes de conectar `dopmi.org`, revisar los enlaces a App Store/Google Play, los casos de ejemplo y las páginas de privacidad y términos.
